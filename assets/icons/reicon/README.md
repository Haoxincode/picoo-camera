# Reicon 图标子集

这里保存 Picoo Camera 实际使用的 Reicon Outline SVG，作为 Android、iOS、Windows、macOS 和 Web 原型的共享图标事实源。

- 上游：`dqev/reicon`
- 固定版本：`974cf2445404d6d59531336c9c8e74f74c0701aa`
- 网格：`24 × 24`
- 许可证：MIT，见同目录 `LICENSE`

只提交产品实际使用的单个 SVG，不引入 Reicon 完整依赖。平台适配产物必须保持相同文件名和语义；Android 的 `res/drawable/reicon_*.xml` 是这些 SVG 的 Vector Drawable 转换结果。
